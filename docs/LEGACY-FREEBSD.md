# Legacy FreeBSD prototype

The files and build scripts that were present before the project pivot describe an experimental FreeBSD-based Brasa prototype. They are retained in Git history for reference, but are **not** the source base for the new Brasa project. Do not use their installer, kernel modules, OSS audio backend, or image-building scripts in the Kubuntu fork.

The user reported that an earlier FreeBSD image installed and started KDE on one physical PC. They also reported incomplete HDMI/USB audio, graphics acceleration problems, and nonfunctional Brasa audio apps. Those results belong only to that retired prototype and do not establish any capability of the new Kubuntu-based Brasa.

The current project baseline and plan are documented in [`README.md`](../README.md), [`PROJECT.md`](PROJECT.md), [`KUBUNTU-FORK.md`](KUBUNTU-FORK.md), and [`USB-AUDIO.md`](USB-AUDIO.md).
