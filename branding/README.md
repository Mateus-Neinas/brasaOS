# Identidade visual Brasa

Ativos originais do projeto Brasa. Não incorporam logotipos ou arquivos gráficos do Kubuntu, Ubuntu ou Canonical.

## Conceito

A marca usa uma brasa formada por três ondas verticais: calor, áudio e fluxo contínuo. Paleta inicial: carvão `#171923`, coral `#FF684A`, âmbar `#FFB454` e marfim `#FFF7EC`. O símbolo é vetorial e pode ser redimensionado sem perda.

## Uso

- Nome do sistema: **Brasa OS**.
- Descrição curta: **Sistema operacional baseado no Kubuntu**.
- Aviso de origem: use `NOTICE.txt` em páginas “Sobre”, documentação e materiais de instalação.
- Não use “Kubuntu” como parte do nome do produto ou como selo de aprovação. É permitido explicar factualmente a origem do projeto.
- Não publique a ISO derivada como legalmente pronta até concluir a revisão de marcas, binários, licenças, avisos de copyright e componentes de firmware.

## Estado

São apenas ativos e textos de identidade do projeto. Ainda não foram aplicados à ISO nem ao sistema instalado. A imagem Kubuntu de upstream fica imutável.
